Back-End 6D Digital Twin Simulator

Die Bonding → Wire Bonding → Molding → Saw/Dicing → Package Testing — all 5 modules built on the same 6D framework as Front-End (03): 3D geometry + 4D time + 5D data/AI + 6D spatial pattern intelligence.
